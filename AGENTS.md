# Agent instructions

## Docs pointers

User docs live in `devkindhq/routineos-docs` (docs.routineos.org). Any change to user-visible behaviour must update, in the same piece of work:

- `CHANGELOG.md` here
- the matching docs pages: guide or concept, CLI reference, definition and store references, Desk pages, glossary, `/contributing/changelog`
- `skills/routineos/references/` and the `SKILL.md` row if Claude needs it
- `references/platform-facts.md` for any platform claim

List the docs pages touched, or the docs PR link, in the PR description.

See `CONTRIBUTING.md` for the other rules.
