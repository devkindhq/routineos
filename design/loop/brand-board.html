Concept 02 RoutineOS brand board

Loop

The identity is the lifecycle itself. Eight stages, Discover to Retire, sit on one ring, each segment a stage, each with the evidence that must exist before moving on. A small gap at the top is where a run re-enters, so the mark reads as the "O" in OS and as a cycle that never quite closes on its own: a person has to look, decide, and let the next run in. The palette stays on porcelain and cobalt, with an eight-step stage spectrum reserved for the lifecycle.

03 Logo system

One ring, eight segments, one way back in.

The mark is drawn, never typed: a ring split into the eight lifecycle stages, with a wider gap at twelve o'clock. In the wordmark the ring takes the place of the "O", so "OS" is spelled by the cycle itself.

Don'ts

Shown small, crossed

Don't close the gap. A closed ring has no way back in; the loop needs a person.

04 The Desk sub-brand
Desk

RoutineOS is the framework. The Desk is where people meet the routines.

A rounded square, like a table seen from above, with one ring dot at its centre: the routine you sit down with. Ink, never cobalt, so it never competes with the RoutineOS ring. The word "Desk" is set in Instrument Sans 600 at normal width.

"A desk is where you come, take a seat, look, think, understand, and then leave." Kazim Ali, Devkind

07 Colour

Porcelain, cobalt, and eight stages.

Light first. Cobalt is the only brand colour in UI chrome. The stage spectrum is reserved for the lifecycle: segments, stage icons and stage labels. Every stage hue passes AA as text on white, so a stage name can be written in its own colour.

08 The lifecycle

The ring, opened up.

Each segment is a stage. Each stage has exit evidence: the thing that must exist before moving on. Cut the ring at its gap and lay it flat, and you get the lifecycle every routine follows.

01 · optional

Discover

Interview, or read a brief the person already has.

Exit evidence
A written brief the person accepted.
02

Design

Pick routines, the mix of code and model, store, gates, secrets pattern, cost; list risks.

Exit evidence
A design the person approved, risks listed.
03

Build

Scaffold, write prompts and scripts, build the Desk.

Exit evidence
Lint passes; every external contact declared.
04

Verify

Dry checks, then a real report-only first run.

Exit evidence
A run record exists and the person looked at the output.
05

Deploy

Show the permission screen, create the routine and triggers, load seed data.

Exit evidence
The routine is listed on the account with the stated schedule.
06

Operate

Read run records, watch health and cost, relay approvals.

Exit evidence
Health and cost visible on the Desk.
07

Improve

Change or add routines and integrations without losing data.

Exit evidence
Change applied, verified, summarised in plain words.
08

Retire

Pause or archive cleanly, remove secrets.

Exit evidence
Nothing scheduled; secrets deleted.
Done means live and tested Not live Live, not yet tested Live and tested

"Only live and tested counts as finished. An agent saying a routine works is not evidence."
